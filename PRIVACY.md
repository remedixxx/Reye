# Privacy Policy

Effective date: September 10, 2026

Reye works fully offline. It does not create user accounts and does not collect, sell, share, or transmit personal data.

Reye stores timer state, reminder preferences, theme, and language locally on the user's device. This data is used only to provide the application's features and can be removed by clearing the app data or uninstalling Reye.

On Android, Reye may request notification permission so it can show timer and break reminders. It may also use the full-screen notification capability when the user explicitly enables the reminder-screen option. Reye does not request location, contacts, camera, microphone, storage, advertising, or Android overlay permission.

Reye contains no ads, analytics SDKs, tracking SDKs, or remote backend services.

Future versions that change these practices must update this policy and its effective date before release.

Privacy questions can be submitted through the Issues page of the public Reye repository.

Reye کاملاً آفلاین کار می‌کند. این برنامه حساب کاربری ایجاد نمی‌کند و هیچ داده شخصی را جمع‌آوری، فروخته، به‌اشتراک گذاشته یا ارسال نمی‌کند.

وضعیت تایمر، تنظیمات یادآوری، پوسته و زبان فقط روی دستگاه کاربر ذخیره می‌شوند. این اطلاعات تنها برای عملکرد برنامه استفاده می‌شوند و با پاک‌کردن داده‌های برنامه یا حذف Reye از بین می‌روند.

در اندروید، Reye ممکن است برای نمایش شمارش زمان و یادآوری استراحت، مجوز اعلان را درخواست کند. قابلیت اعلان تمام‌صفحه نیز فقط در صورت فعال‌کردن گزینه مربوط توسط کاربر استفاده می‌شود. برنامه به موقعیت مکانی، مخاطبان، دوربین، میکروفون، حافظه، تبلیغات یا مجوز نمایش شناور اندروید دسترسی نمی‌خواهد.

Reye شامل تبلیغات، ابزار تحلیل رفتار، ابزار ردیابی یا سرویس پشتیبان اینترنتی نیست.
