# Reye

فارسی | [English](README.md)

Reye یک برنامه متن‌باز و آرام برای یادآوری استراحت از صفحه‌نمایش در ویندوز و اندروید است. این برنامه با چرخه‌های زمانی قابل تنظیم و بر پایه عادت ۲۰-۲۰-۲۰، به کاربر کمک می‌کند وقفه‌های منظم‌تری هنگام کار با صفحه‌نمایش داشته باشد.

Reye کاملا آفلاین کار می‌کند و حساب کاربری، تبلیغات، آمارگیری، ردیابی، سرور یا جمع‌آوری اطلاعات شخصی ندارد. این برنامه یک ابزار یادآوری است و جایگزین توصیه یا درمان پزشکی نیست.

## دانلود

### [دانلود آخرین نسخه Reye](../../releases/latest)

بخش Releases همین مخزن، تنها مرجع رسمی دانلود برنامه است. فایل مناسب دستگاه خود را انتخاب کنید:

| پلتفرم | فایل | کاربرد |
| --- | --- | --- |
| ویندوز ۱۰/۱۱ نسخه ۶۴ بیتی | `Reye-Windows-x64-Setup-vX.Y.Z.exe` | نصب‌کننده پیشنهادی |
| ویندوز ۱۰/۱۱ نسخه ۶۴ بیتی | `Reye-Windows-x64-Portable-vX.Y.Z.zip` | نسخه پرتابل بدون نصب |
| اندروید ۷ به بالا | `Reye-Android-vX.Y.Z.apk` | نصب مستقیم روی اندروید |

برای هر فایل دانلود، یک فایل هم‌نام با پسوند `.sha256` وجود دارد. فایل‌های اجرایی در GitHub Releases قرار می‌گیرند و عمدا داخل کد منبع مخزن ذخیره نمی‌شوند.

## نصب

### نصب‌کننده ویندوز

1. وارد صفحه [آخرین نسخه](../../releases/latest) شوید.
2. فایل `Reye-Windows-x64-Setup-vX.Y.Z.exe` و فایل `.sha256` مربوط به آن را دانلود کنید.
3. نصب‌کننده را اجرا کرده و مراحل را ادامه دهید. نصب برای کاربر فعلی انجام می‌شود و دسترسی Administrator لازم ندارد.
4. Reye را از منوی Start یا میان‌بر دسکتاپ اجرا کنید.

نسخه ویندوز فعلا با گواهی تجاری Authenticode امضا نشده است؛ در نتیجه ممکن است Windows SmartScreen پیام **Unknown publisher** نمایش دهد. فقط زمانی ادامه دهید که فایل را از صفحه رسمی Releases همین مخزن گرفته‌اید و مقدار SHA-256 آن صحیح است.

### نسخه پرتابل ویندوز

1. فایل `Reye-Windows-x64-Portable-vX.Y.Z.zip` را دانلود کنید.
2. تمام محتوای ZIP را در یک پوشه استخراج کنید.
3. فایل `Reye.exe` را از همان پوشه اجرا کنید.

فقط فایل `Reye.exe` را جدا نکنید؛ DLLها و پوشه `data` کنار آن برای اجرای برنامه لازم هستند.

### اندروید

1. با گوشی وارد صفحه [آخرین نسخه](../../releases/latest) شوید.
2. فایل `Reye-Android-vX.Y.Z.apk` را دانلود کنید.
3. اگر اندروید درخواست کرد، مجوز **Install unknown apps** را فقط برای مرورگر یا فایل‌منیجری که APK را باز می‌کند فعال کنید.
4. برنامه را نصب و اجرا کنید.
5. مجوز اعلان‌ها را فعال کنید تا شمارنده دائمی و یادآوری‌های پس‌زمینه کار کنند.

پس از نصب می‌توانید مجوز **Install unknown apps** مرورگر را دوباره غیرفعال کنید. نسخه‌های بعدی که با کلید انتشار یکسان امضا شوند، بدون حذف تنظیمات محلی روی نسخه فعلی نصب خواهند شد.

### بررسی صحت فایل در ویندوز

PowerShell را در پوشه دانلود باز کرده و اجرا کنید:

```powershell
Get-ChildItem .\Reye-* -File | Where-Object Extension -ne '.sha256' | Get-FileHash -Algorithm SHA256
Get-Content .\*.sha256
```

هش فایل دانلودشده را با مقدار موجود در فایل `.sha256` همان نسخه مقایسه کنید. اگر این دو مقدار متفاوت بودند، فایل را نصب نکنید.

## امکانات

- تنظیم مدت تمرکز، زمان نمایش شمارش معکوس نهایی و مدت استراحت
- محاسبه زمان بر اساس timestamp و بازیابی صحیح چرخه پس از اجرای دوباره برنامه
- کنترل‌های شروع، توقف موقت، ریست، تعویق پنج‌دقیقه‌ای و خروج کامل
- رابط کاربری فارسی و انگلیسی
- پوسته روشن، تیره و هماهنگ با سیستم
- ذخیره محلی تنظیمات و وضعیت تایمر
- شمارنده گوشه صفحه، یادآور همیشه‌بالا، آیکن System Tray و اجرای خودکار در ویندوز
- اعلان دائمی زمان باقی‌مانده و اعلان استراحت در اندروید
- امکان اختیاری باز شدن صفحه تمام‌صفحه یادآور در اندروید
- امکان اختیاری توقف تایمر هنگام خاموش بودن صفحه گوشی
- بدون مجوز شناور اندروید، بدون Exact Alarm، بدون Foreground Service و بدون افزونه اعلان بومی ویندوز

## روش کار

چرخه پیش‌فرض برنامه به این شکل است:

1. یک بازه تمرکز ۲۰ دقیقه‌ای شروع می‌شود.
2. تایمر بدون نمایش دائمی یک شمارنده بزرگ در پس‌زمینه ادامه پیدا می‌کند.
3. در ۲۰ ثانیه پایانی، شمارنده کوچک ویندوز ظاهر می‌شود یا زمان اعلان اندروید به‌روزرسانی می‌شود.
4. در پایان زمان، برنامه با یک پیام آرام یادآوری می‌کند که برای ۲۰ ثانیه به نقطه‌ای دور نگاه کنید.
5. با تایید انجام استراحت، چرخه جدید آغاز می‌شود؛ همچنین می‌توانید یادآوری را پنج دقیقه به تعویق بیندازید.

تمام زمان‌ها از بخش تنظیمات قابل تغییر هستند. منطق تایمر بر زمان‌های ذخیره‌شده تکیه دارد و برای ادامه کار در پس‌زمینه به اجرای دائمی Dart Timer وابسته نیست.

## رفتار در پلتفرم‌ها

### ویندوز

- در ثانیه‌های پایانی، پنجره اصلی به شمارنده‌ای کوچک و قابل جابه‌جایی در گوشه صفحه تبدیل می‌شود.
- شمارنده و صفحه یادآوری هنگام نمایش همیشه بالای پنجره‌های دیگر قرار می‌گیرند.
- محل شمارنده و حالت نمایش یادآوری از تنظیمات قابل انتخاب است.
- با Minimize کردن، برنامه به بخش آیکن‌های مخفی نوار وظیفه می‌رود.
- در هر لحظه فقط یک نمونه از Reye قابل اجرا است.
- یادآوری‌ها با پنجره Flutter نمایش داده می‌شوند و افزونه اعلان بومی ویندوز عمدا استفاده نشده است.

### اندروید

- هنگام فعال بودن چرخه، یک اعلان دائمی زمان باقی‌مانده را نشان می‌دهد.
- در اندروید ۱۳ به بالا مجوز اعلان درخواست می‌شود. در صورت رد مجوز، یادآوری داخل برنامه همچنان کار می‌کند.
- گزینه اختیاری **باز کردن صفحه یادآوری** از سازوکار Full-screen notification اندروید استفاده می‌کند.
- در اندروید ۱۴ به بالا ممکن است لازم باشد مجوز Full-screen intent را از تنظیمات سیستم فعال کنید.
- گزینه اختیاری **توقف هنگام خاموش بودن صفحه**، مدت خاموشی صفحه را از چرخه تمرکز حذف می‌کند.
- برنامه مجوز `SYSTEM_ALERT_WINDOW` یا Exact Alarm درخواست نمی‌کند.

سیاست‌های باتری اندروید و شرکت سازنده گوشی ممکن است یادآوری پس‌زمینه را با تاخیر اجرا کنند. باز شدن تمام‌صفحه نیز تحت کنترل سیستم‌عامل است و روی همه دستگاه‌ها تضمین نمی‌شود؛ در این شرایط اعلان با اولویت بالا به عنوان جایگزین نمایش داده می‌شود.

## حریم خصوصی و مجوزها

Reye تنظیمات و وضعیت تایمر را با `shared_preferences` فقط روی دستگاه ذخیره می‌کند و هیچ اطلاعات شخصی را جمع‌آوری یا ارسال نمی‌کند. متن کامل در [سیاست حریم خصوصی](PRIVACY.md) موجود است.

مجوزهای اندروید فقط برای امکانات برنامه استفاده می‌شوند:

- اعلان‌ها: نمایش زمان باقی‌مانده و یادآوری استراحت
- Full-screen intent: باز کردن اختیاری صفحه یادآوری هنگام پایان زمان

اجرای خودکار همراه ویندوز کاملا اختیاری است. هیچ مجوزی برای تبلیغات، ردیابی یا جمع‌آوری داده استفاده نمی‌شود.

## پلتفرم‌های پشتیبانی‌شده

- ویندوز ۱۰ یا ۱۱ نسخه ۶۴ بیتی
- اندروید ۷ یا جدیدتر (`API 24+`)

iOS، macOS، Linux و Web عمدا پشتیبانی نمی‌شوند.

## ساخت از کد منبع

### پیش‌نیازها

- نسخه Stable فلاتر با Dart `>=3.12.0 <4.0.0`
- Visual Studio به همراه **Desktop development with C++** برای ساخت ویندوز
- Android SDK و JDK 17 برای ساخت اندروید
- Git

پس از Clone کردن مخزن، پروژه را بررسی کنید:

```bash
flutter pub get
flutter analyze
flutter test
```

اجرا روی ویندوز:

```bash
flutter run -d windows
```

اجرا روی اندروید:

```bash
flutter run -d android
```

ساخت خروجی Release:

```bash
flutter build apk --release
flutter build windows --release
```

ساخت Release اندروید به کلید امضای شخصی شما و فایل `android/key.properties` نیاز دارد. از `android/key.properties.example` شروع کنید و فایل واقعی properties یا keystore را هرگز Commit نکنید. شناسه دائمی برنامه اندروید `com.reye.app` است.

راهنمای کامل امضا، بسته‌بندی، هش‌ها، ساخت نصب‌کننده، نام فایل‌های خروجی و انتشار در گیت‌هاب در [docs/RELEASING.md](docs/RELEASING.md) قرار دارد.

## ساختار پروژه

کد مشترک Flutter شامل مدل دامنه تایمر، کنترلرهای Riverpod، ذخیره‌سازی، ترجمه، پوسته و رابط کاربری است. رفتار وابسته به سیستم‌عامل پشت سرویس‌های جدا قرار دارد:

- `lib/android/`: سرویس‌های اعلان، زمان‌بندی، وضعیت صفحه و مجوزهای اندروید
- `lib/windows/`: سرویس‌های پنجره، System Tray، اجرای خودکار و جلوگیری از اجرای چند نمونه
- `android/`: کانال‌های حداقلی Kotlin برای ارتباط با امکانات سیستم اندروید
- `windows/`: تنظیمات Runner بومی ویندوز
- `test/`: تست محاسبات تایمر، تغییر وضعیت‌ها، اعتبارسنجی تنظیمات، Snooze و بازیابی

## نسخه‌بندی و انتشار

Reye از نسخه‌بندی معنایی در `pubspec.yaml` با الگوی `major.minor.patch+build` استفاده می‌کند؛ برای مثال `1.0.0+1`. هر انتشار عمومی باید یک Git tag هماهنگ مانند `v1.0.0` و یک ورودی در [CHANGELOG.md](CHANGELOG.md) داشته باشد.

نسخه فعلی Flutter ممکن است درباره استفاده `shared_preferences_android` از Kotlin Gradle Plugin قدیمی هشدار بدهد. این هشدار مربوط به مهاجرت dependency بالادستی است و در صورت موفق بودن Build، خروجی را نامعتبر نمی‌کند. Built-in Kotlin باید زمانی فعال شود که همه افزونه‌های اندروید موجود در dependency graph از آن پشتیبانی کنند.

## محدودیت‌های فعلی

- شمارنده ویندوز به جای ساخت پنجره بومی دوم، از همان پنجره اصلی Flutter استفاده می‌کند.
- نسخه امضانشده ویندوز ممکن است هشدار SmartScreen نمایش دهد.
- زمان‌بندی پس‌زمینه اندروید تحت تاثیر سیاست‌های باتری سیستم‌عامل و سازنده گوشی است.
- یادآوری تمام‌صفحه اندروید ممکن است به دلیل محدودیت سیستم‌عامل فقط به شکل اعلان نمایش داده شود.
