# Changelog

All notable changes to Reye are documented in this file.

## Unreleased

- No changes yet.

## 1.0.0 - 2026-09-10

- Initial public release for Windows and Android.
- Added timestamp-based focus cycles, pause/resume/reset, and snooze.
- Added Windows floating countdown, reminder window, system tray, single-instance behavior, and launch on startup.
- Added Android ongoing countdown and break notifications.
- Added optional Android reminder-screen launch and pause while the screen is off.
- Added English and Persian interfaces, local persistence, and light/dark themes.
